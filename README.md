# Supabase Agent Skill

A general-purpose Supabase skill for AI coding agents and development workflows across web, mobile, backend, SaaS, APIs, and other application types.

This repository is derived from the official Supabase `agent-skills` repository, specifically `skills/supabase`, and retains the upstream MIT license. The skill is intentionally platform-agnostic and is not tied to Lovable, NHM, or any specific project.

## Contents

- `SKILL.md` — core Supabase agent instructions
- `references/skill-feedback.md` — upstream feedback workflow reference
- `assets/feedback-issue-template.md` — upstream feedback issue template
- `LICENSE` — upstream MIT license
- `agents/openai.yaml` — optional ChatGPT UI metadata; agents that do not use it can ignore it
